## Proyectos destacados

### AI Content Generator
**Generador de contenido para redes sociales con IA generativa y fuentes científicas.**

Una aplicación que demuestra cómo combinar **LLMs, RAG y APIs científicas** para crear contenido adaptado a múltiples plataformas con rigor técnico.

- **Qué resuelve:** automatizar la creación de contenido enriquecido sin costes de API (Groq gratuito)
- **Cómo:** pipeline RAG que busca papers en arXiv, los indexa localmente, y los usa como contexto para generar mejor contenido
- **Stack:** Python, LangChain, Groq, ChromaDB, Streamlit, sentence-transformers
- **Aprendizajes:** arquitectura RAG, lazy loading, manejo de límites de rate-limiting en APIs, diseño de prompts especializados por plataforma

[→ Ver repositorio](https://github.com/Bootcamp-IA-P6/project10_Gabriela)
